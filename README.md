# Castle Empire

The repository hosts Castle Empire, a browser-based kingdom game with a 3D kingdom view centered on its castle. The playable territory spans 354×354 tiles—about three times the former area—while keeping the castle and camera scale unchanged.

It includes four railway loops around the castle, each with an articulated five-car train: two fast bullet trains (black and yellow-white) and two regular trains. The expanded outskirts add irregular ponds, impassable rocky ridges, and dense forest groves, alongside the detailed station, overbridges, airports, buildings, bridges, and vehicle traffic.

Open the live game at https://lm0e7.github.io/findtime/
